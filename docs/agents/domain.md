# Domain docs

O Vortix é um projeto single-context.

## Antes de explorar

- Leia `GLOSSARY.md`, se existir.
- Leia ADRs relevantes em `docs/adr/`, se existirem.
- Se esses arquivos não existirem, prossiga sem destacar a ausência; crie-os quando termos ou decisões do domínio forem definidos.

## Vocabulário e decisões

Use os termos do glossário quando disponível. Se uma mudança contrariar um ADR existente, aponte o conflito antes de propor outra decisão.
