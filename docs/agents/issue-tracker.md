# Issue tracker: GitHub

Issues e specs do Vortix ficam em https://github.com/JeffyMesquita/Vortix/issues.

## Convenções

- Consulte issues existentes antes de abrir outra.
- Use os formulários de bug e feature request em `.github/ISSUE_TEMPLATE/`.
- Relacione PRs com `Closes #123` quando resolverem uma issue.
- PRs não são tratados como fila de solicitações.
- Prefira o conector GitHub do Codex; use `gh` CLI somente quando instalado e autenticado.
