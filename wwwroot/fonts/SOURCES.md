# Local font assets

All fonts are served from this folder; the app makes no runtime requests to font CDNs.
Only WOFF2 subsets used by this UI are included. Original licenses are in licenses/.

- Fira Code: @fontsource-variable/fira-code 5.3.0, OFL-1.1.
- JetBrains Mono: @fontsource-variable/jetbrains-mono 5.3.0, OFL-1.1.
- Cascadia Code: @fontsource-variable/cascadia-code 5.3.0, OFL-1.1.
- Cascadia Mono: @fontsource-variable/cascadia-mono 5.3.0, OFL-1.1.
- IBM Plex Mono: @fontsource/ibm-plex-mono 5.3.0, OFL-1.1.

IBM Plex Mono replaces Consolas because Consolas is proprietary and is not bundled.
